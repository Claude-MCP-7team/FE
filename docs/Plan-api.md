# 신청 계획 API 연결

BE `dev`의 `POST /v1/plan`은 저장된 `UserProfile`을 받아 정책별 신청 상태·마감일·권장 준비 시작일과 중복 서류 목록을 반환합니다. FE는 BE가 계산한 영업일과 발급 소요일을 재계산하지 않고, 서류 체크리스트와 신청 Timeline으로 표시합니다.

서버 모드의 `#/schedule` 화면은 세션 프로필을 조회한 뒤 API를 호출합니다. 서류 준비 완료 체크는 화면 상태로만 관리하며, 실제 증빙 저장 API는 계약이 확정된 뒤 추가합니다. API 주소가 없으면 기존 Mock 일정 화면을 유지합니다.
