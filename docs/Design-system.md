## 1. 팔레트 통일 【확정 · 2026-09-19】

**결정: 녹색 체계로 통일했다 (선택지 A).**

`src/profile.css`가 파랑/slate 계열(`#5B8DEF`, `#F8FAFC`, `#1E293B`)을 따로 쓰고 있어, 결과 화면에서 프로필로 이동하면 다른 제품처럼 보였다. 화면 수가 5:1이고, 파랑으로 가면 `FUTURE_PASS`(`#325975`)가 주조색과 충돌해 상태색을 다시 잡아야 하므로 녹색을 택했다.

### 토큰을 한 파일로 뺐다

`src/tokens.css`가 유일한 정의다. `index.html`과 `profile.html`이 함께 불러온다.

그 전에는 `styles.css`가 토큰을 들고 있었는데 **`profile.html`은 그 파일을 불러오지 않았다.** 두 화면이 각자 색을 들고 있던 구조적 원인이다. `styles.css`를 프로필 페이지에도 불러오는 방법은 쓰지 않았다 — `header`·`main` 같은 요소 선택자가 프로필 레이아웃에 함께 걸린다.

접근성 미달 4건을 고쳤다. **색 체계는 바꾸지 않았고, 대비가 부족한 경계선만 올렸다.**

| 파일 | 대상 | 변경 | 결과 |
| --- | --- | --- | --- |
| `src/styles.css` | `input`, `select` 테두리 | `#a8b7ad` → `#7d8f84` | 2.09 → 3.42 |

## 8. 스타일이 없는 클래스

`dev`가 판정·역질문·조합 화면을 연결하면서 추가한 아래 클래스에 **CSS 규칙이 없다.**
마크업에만 존재하고 아무 스타일도 적용되지 않는다.

| 클래스 | 쓰이는 곳 | 시각적 구분이 필요한가 |
| --- | --- | --- |
| `.judgement-summary` | Dashboard 요약 | 공통 `.summary`로 충분해 보임 |
| `.judgement-card` | 정책 카드 | 공통 `.card`로 충분해 보임 |
| `.question-card` | 역질문 카드 | 공통 `.card`로 충분해 보임 |
| ~~`.conflict`~~ | 조합에서 제외된 정책의 충돌 표시 | **정의함** (2026-09-19) |

`.notice-inline`과 `.conflict`는 정의했다. 나머지 셋은 공통 클래스로 형태가 잡히므로 제거해도 되지만, 앞으로 화면별 조정이 필요할 수 있어 판단을 보류한다.

이 문서는 색·형태 토큰만 다루므로, 새 스타일을 정의할 때도 2~4장의 토큰 안에서 조합한다.

| | `.badge` (판정 상태) | `.chip` (신뢰도) |
| --- | --- | --- |
| 배경 | 상태색으로 채움 | 없음 |
| 테두리 | 없음 | 1px `var(--line-strong)` |
| 글자 | 상태색 (짙은 쪽) | `#4f5c54` |

| 라운드 | 24px | 24px |

**판정 상태 4색은 판정 상태만 뜻한다.** 신뢰도·조합·서류 등 다른 축에 이 색을 쓰지 않는다.

대비: 칩 글자 7.02(흰 배경) / 6.51(페이지 배경), 테두리 3.42 / 3.18. 모두 기준을 넘는다.

## 12. 제외된 정책 블록 (`.conflict`)

조합에서 제외된 정책의 사유를 담는다. 여러 개가 `<details>` 안에 쌓인다.

| 항목 | 값 |
| --- | --- |
| 배경 | `var(--bg)` — 흰 카드 위에서 한 단 들어가 보인다 |
| 테두리 | 1px `var(--line)` + 좌측 3px `var(--line-strong)` |
| 라운드 | 12px |
| 안쪽 여백 | 14px 16px |
| 블록 간격 | 12px |

**상태색을 쓰지 않는다.** 제외는 판정이 아니다. 여기에 `FAIL` 빨강을 쓰면 "부적격 판정"으로 읽혀, 신뢰도에 `UNKNOWN` 노랑을 썼던 것과 같은 실수가 된다. 좌측 굵은 선은 인용 블록(`blockquote`)과 같은 어법이되 색만 중성이다.

안에 들어가는 순서는 **정책명 → (신뢰도 칩) → 우리가 쓴 사유 → 원문 인용**이다.
인용 블록은 `.conflict`의 `--bg` 위에서 다시 흰 배경을 써서 한 겹 더 구분된다.
