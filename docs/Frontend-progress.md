# Frontend 진행 기록

## 2026-09-19 · Design 규격 문서 착수

- **완료:** 판정 상태·근거 표현 규격(`Design-states.md`)과 디자인 시스템(`Design-system.md`) 초안 작성. 현재 코드의 색·타이포·형태 토큰을 역정리하고 명도 대비 15건 측정. 미달 4건(입력·보조 버튼 테두리, 두 파일 모두)을 수정하고 `--line-strong` 토큰을 분리. 카드 테두리 등 장식용 경계선은 유지.
- **다음:** S-1 상태 매핑 표와 S-2 FUTURE_PASS 판별 방식을 BE와 확정. 이후 역질문·조합·서류 화면 시안.
- **막힌 점:** `verdict` 3개를 화면 4분류로 접는 규칙이 없어 Dashboard 구현이 대기 중. 브라우저 실행 환경이 없어 키보드·스크린리더·실기기 검증 미완료.
- **결정 필요:** S-1~S-6(상태 매핑, FUTURE_PASS 판별, NEEDS_INFO/NEEDS_REVIEW 구분, ESTIMATED 표시, 원문 URL 부재 시 근거 표시, 긴 인용문 처리), D-1~D-3(팔레트 두 벌 통일, 반응형 분기점, 간격 스케일).
