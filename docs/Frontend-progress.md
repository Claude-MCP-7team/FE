# Frontend 진행 기록

## 2026-09-12

- **완료:** M0 화면 경로 7개, 공통 상태·카드·필터·정책별 상세를 Mock JSON에 연결. 원본 초안 보존. 계약 테스트 3개 및 문법 검사 통과. 개발 서버와 Mock JSON HTTP 200 확인.
- **다음:** BE/AI와 `Frontend-contract.md` 및 JSON 계약 확정. M0 통과 후 M1 사용자 입력 Validation 및 Profile 저장/조회 연결.
- **막힌 점:** BE API/확정 DTO/AI 결과 없음. 브라우저 연결이 없어 실제 렌더링, 키보드 이동, 반응형 검증은 미완료.
- **결정 필요:** API 계약·인증·분석 작업 상태·질문 DTO 확정 및 FE 와이어프레임 검토.
