# 청년 지원정책 자격 판정 및 조합 최적화 AI 서비스

> 기존 계획서의 추출 텍스트를 문단·어순·띄어쓰기 중심으로 정리한 문서입니다. 아래 내용은 제안 당시의 배경과 목표이며 현재 구현 완료 범위를 뜻하지 않습니다.

## 제안 배경

정부 청년정책 통합플랫폼 온통청년의 신청자격 자가진단을 직접 사용해 보았다. 한 정책에서 7개 자격조건 중 6개가 적격이었으나, 거주지역 조건 하나 때문에 최종 결과는 “부적격”이었다. 소득·학력·취업상태·혼인상태를 통과했음에도 화면은 거기서 종료되었다. 사용자가 실제로 알고 싶은 것은 “그래서 나는 무엇을, 언제, 어떻게 신청할 수 있는가?”이다.

현재 서비스의 한계는 세 가지다.

1. 판정 이후의 설명과 대안이 부족하다. 부적격 사유는 표시되지만 언제 자격이 생기는지, 대신 무엇을 받을 수 있는지는 안내하지 않는다. 판단하지 못한 항목은 “확인불가”로 남는다.
2. 정책을 하나씩 확인해야 한다. 약 3,000개 정책 중 무엇을 볼지 사용자가 결정해야 하며, 여러 공고문에 흩어진 중복수혜 제한 조항도 직접 비교해야 한다.
3. 고정 필터로 표현하기 어려운 조건이 있다. 지역·연령·소득·학력·취업상태 등의 8개 축만으로는 “6개월 이상 계속 거주”, “부모 합산 소득 기준”, “타 유사사업 참여 이력 없음” 같은 조건을 충분히 다루기 어렵다.

## 기존 해결 방법과 한계

온통청년 자가진단은 공공 마이데이터 연계로 서류 없이 자격을 검증할 수 있지만 정책별 판정에 그친다. 보조금24는 수혜 서비스를 통합 안내하지만 자격 사유나 대안 제시가 부족하다. 민간의 웰로·지원금 AI는 맞춤 추천과 마감 알림을 제공하지만 목록 제시에서 종료된다. 정보를 개인 상황에 적용하고 행동으로 연결하는 단계는 사용자의 몫으로 남는다.

## 제안하는 해결 방법

공고문 이해부터 신청 준비까지를 하나의 AI 처리 흐름으로 연결한다.

1. 공고문에서 자격요건·제외대상·필요서류·마감일을 추출해 표준 스키마로 구조화한다.
2. 조건 입력 1회로 약 3,000개 정책의 일괄 판정을 목표로 한다.
3. 판정 결과에 근거와 향후 가능 시점을 함께 제시한다.
4. 판단에 필요한 정보가 없으면 사용자에게 다시 질문한다.
5. 여러 공고문의 제외 조항을 교차 대조해 정책 조합을 산출한다.
6. 서류별 발급 소요일을 반영해 신청 일정을 역산한다.

## 차별성

- 적격·부적격 결과와 함께 이유와 향후 가능 시점을 제시한다.
- “확인불가” 항목을 추가 질문으로 확인해 고정 필터 밖의 조건도 다룬다.
- 정책을 독립적으로 매칭하는 데서 나아가 중복수혜 제한을 교차 판정하고, 어떤 정책을 함께 받는 것이 유리한지 안내한다.

## 활용 도구와 구현 방향

Claude Code 멀티에이전트를 핵심 도구로 활용한다. 공고문 파싱·조건 구조화·개인조건 대조·역질문 생성·서류 역산을 5개 서브에이전트로 분담하는 구상이다. 자격 판정 오류로 인한 손실을 줄이기 위해 2개 에이전트가 독립 판정하고, 결과가 다르면 사용자에게 확인을 요청하는 교차검증을 적용한다.

데이터는 MCP로 온통청년 청년정책 OPEN API와 공공데이터포털을 연동한다. API 요약 정보만으로 판단하기 어려운 세부 조건은 원문 공고문 파싱으로 보완한다. Python과 웹 인터페이스를 사용하며, 1차 적용 범위는 경기도·용인시·중앙부처 정책으로 한정한다.

## 기대 효과

### 사회적 효과

정책을 잘 찾아보는 능력에 따른 정보 접근성 격차를 줄이고, 실제 자격을 갖춘 청년에게 정책이 도달하도록 돕는다. 정보 부족이나 서류 미비로 신청하지 못하는 사례를 줄이는 것이 목표다.

### 경제적 효과

개인은 중복수혜 제한을 고려한 조합 선택으로 수혜 규모를 높일 수 있다. 정책별 지원 규모 차이가 연 수백만 원에 이르는 사례에서 조합 비교의 이점이 기대된다. 행정 측면에서는 자격 미달 신청과 서류 반려를 줄여 담당자의 심사 부담을 낮추고 예산 집행 효율을 높인다.

### 일상생활의 변화

약 3,000개 정책을 개별 확인하는 과정을 조건 입력 한 번으로 줄이는 것이 목표다. 단순한 “부적격”을 “6개월 후 신청 가능하며, 그 전에는 이 정책을 검토할 수 있음”과 같은 실행 계획으로 연결한다. 서류 준비 기간을 역산해 마감 직전 신청과 서류 미비 반려를 예방한다.
